### 🧩 Technical Co-Founder, [Natural Schema](https://www.naturalschema.com/) (San Jose, CA)

Ask your data in plain English. Natural Schema takes your question, builds a safe read-only ETL, runs it, and hands back the answer. No SQL, no waiting on the data team.

- An agent writes one read-only `SELECT`, checks it against a safety gate, then runs it sandboxed and scoped to just you
- You get a clean table back, with the exact SQL on hand if you want to check the work
- Early access is opening in waves. [Join the waitlist](https://www.naturalschema.com/)
